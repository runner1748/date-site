# Афиша свиданий

Одностраничный сайт: человек открывает ссылку, выбирает до трёх вариантов свидания,
день и время — и получает «билет», текст которого можно скопировать или отправить в мессенджер.

Весь сайт — один файл `index.html`, без сборки и зависимостей.

## Как открыть по ссылке (GitHub Pages)

1. Влить ветку с сайтом в `main`.
2. В репозитории: **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
4. Через минуту сайт будет доступен по адресу
   `https://<логин>.github.io/<имя-репозитория>/`.

Локально достаточно открыть `index.html` в браузере.

## Как поменять варианты свиданий

В `index.html` найдите список `IDEAS` в начале скрипта. Каждая строка — один вариант:

```js
{ cat: "city", title: "Ужин в новом месте", text: "Описание", time: "2 часа", cost: "щедро" }
```

`cat` — категория: `home` (дома), `city` (в городе), `active` (активно), `nature` (на природе).
Время на выбор задаётся в списке `TIMES`, число дней в календаре — в `DAYS_AHEAD`.
