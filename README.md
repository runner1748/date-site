# Афиша свиданий

Сайт, где можно выбрать свидание. Открываешь ссылку, отмечаешь до трёх идей, выбираешь день и время, и получаешь «билет на свидание». Текст билета копируется в один клик и отправляется в любой чат.

## Возможности

- 17 вариантов свиданий в четырёх категориях: дома, в городе, активно, на природе
- выбор до трёх идей, свой вариант и кнопка «выбери за меня»
- календарь на 14 дней вперёд и время на выбор
- билет, который собирается на глазах: подпись, пожелание, номер
- работает на телефоне и компьютере, выбор сохраняется в браузере

## Структура

Весь сайт лежит в одном файле `index.html`. Сборка и зависимости не нужны.

## Запуск

Локально: откройте `index.html` в браузере.

По ссылке (GitHub Pages):

1. Влейте ветку с сайтом в `main`.
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветка `main`, папка `/ (root)`, нажмите **Save**.
4. Через минуту сайт откроется по адресу `https://<логин>.github.io/<имя-репозитория>/`.

## Как изменить варианты

В `index.html` найдите список `IDEAS` в начале скрипта. Один вариант — одна строка:

```js
{ cat: "city", title: "Ужин в новом месте", text: "Описание", time: "2 часа", cost: "щедро" }
```

- `cat`: `home` (дома), `city` (в городе), `active` (активно), `nature` (на природе)
- список времени на выбор: `TIMES`
- число дней в календаре: `DAYS_AHEAD`
- максимум выбранных идей: `MAX_PICKS`
